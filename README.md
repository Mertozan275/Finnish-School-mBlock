# Learning mBlock.cc

## What is mBlock.cc?

**mBlock.cc** is a free coding platform developed for STEM education. It allows students to program robots like **mBot2** using either visual blocks or *Python code* directly from a web browser or desktop app.

## Connecting and Running Programs

1. Connect mBot2 to the computer using a **USB-C cable** (or Bluetooth dongle).
2. Open mBlock, click **Add**, and select **CyberPi / mBot2** from the device library.
3. Click **Connect** and choose the correct serial port.
4. Choose **Live** mode to test instantly or **Upload** mode to save the program onto the robot.

## Block Programming vs. Python

- **Block Programming:** Uses drag-and-drop visual puzzle pieces, making it easy for beginners to avoid syntax errors.
- **Python Programming:** Uses text commands, offering more flexibility, speed, and advanced control for complex projects.

## Why mBlock is Useful for Robotics

mBlock makes learning robotics accessible by letting beginners start with visual blocks and smoothly transition to real Python code in the same environment.
